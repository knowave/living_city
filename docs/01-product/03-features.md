# 기능 범위

> 원본: README §2.2, §2.3

### 2.2 MVP에서 포함하는 기능

- 도시 생성 및 실행
- 시민 자동 생성과 기본 성격 특성
- 시민의 직업, 자산, 소비 상태
- 기업의 고용, 임금, 매출, 현금 잔액
- 정부의 소득세 징수 및 기본 복지 지출
- 시민의 출퇴근과 이동 경로 시각화
- 도시 지도 및 건물 선택
- 시민과 기업 상세 조회
- 월별 경제 통계
- 시뮬레이션 시작, 정지, 배속 변경
- 소득세율 변경
- 이벤트 로그와 주기적 스냅샷

### 2.3 MVP에서 제외하는 기능

- 시민 간 대화 및 LLM 기반 행동
- 결혼, 출산, 사망 등 세대 변화
- 완전한 주택시장과 부동산 거래
- 대출, 은행, 투자 및 금융시장
- 상세한 교통량과 차량 충돌
- 복잡한 생산 공정과 실물 재고
- 도시 간 무역
- 멀티플레이어 및 공동 정책 결정

단, 제외한 기능을 나중에 추가할 수 있도록 핵심 데이터 모델의 확장성은 유지한다.
