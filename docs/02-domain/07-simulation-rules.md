# Simulation Rules

> 원본: README §2.1(시간 규칙), §3.7(정책 적용 문장), §9.4(마지막 항목), §6.3, §7.3

### 시간 규칙

| 항목 | 기본값 |
|---|---|
| 초기 시간 단위 | 1 Tick = 시뮬레이션 1시간 (하루 = 24 Tick) |
| 시간 배율 | 정지, 1배속, 4배속, 16배속 |
| 1배속 기준 | 현실 2초 = 시뮬레이션 1일(24 Tick), Tick 간격 약 83ms |

시뮬레이션의 월은 30일, 연도는 12개월인 가상 달력으로 단순화한다.

### 정책 적용 시점

정책 변경은 명령으로 접수하며, 다음 시뮬레이션 Tick의 명확한 경계에서 적용한다.

- 정책 변경 명령은 지정된 Tick 경계에서 적용한다.

> 코드 기준 갱신: 적용 Tick은 WorldPolicy.effective_tick으로 표현한다 (`simulation_engine/src/simulation_engine/entities/policy.py:12`). 적용 로직 자체는 아직 구현되지 않았다.

### 6.3 자금 보존 원칙

초기 세계 생성 이후에는 원칙적으로 시민, 기업, 정부의 자금 합계가 임의로 증가하거나 감소하지 않아야 한다.

급여 지급, 세금, 소비, 복지 지급 등은 모두 자금 이전 거래로 처리한다.

화폐 발행, 은행 대출, 외부 무역 등의 시스템을 추가하기 전까지는 자금 보존을 주요 불변식으로 둔다.

### 7.3 결정적 실행

시뮬레이션 엔진은 난수 시드와 실행 규칙 버전을 관리한다.

동일한 초기 상태, 동일한 정책 입력 순서, 동일한 엔진 버전, 동일한 난수 흐름에서 동일한 결과가 나오도록 설계한다.

가능하면 난수 스트림을 시민, 이벤트 종류, Tick 기준으로 분리하여 처리 순서 변경이 결과 전체를 불필요하게 흔들지 않도록 한다.
