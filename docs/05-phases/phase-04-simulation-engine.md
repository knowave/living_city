# Phase 4 — 시뮬레이션 엔진
> 원본: README §12 Phase 1(도메인·인터페이스), Phase 3

## 목표
핵심 도메인 모델과 엔진 입출력 인터페이스를 확정하고, UI 없이 도시가 독립적으로 진행되는 시뮬레이션 엔진을 만든다.

## 작업
- 도메인 모델 확정
- 엔진 입력 및 출력 인터페이스 정의
- 도시 생성
- 시민과 기업 초기화
- 시뮬레이션 시간
- 행동 결정 엔진
- 시드 기반 난수
- 상태 전이 및 엔진 테스트

## 완료 기준
원본 Phase 1: 세계 상태와 핵심 도메인을 코드로 표현하고 단위 테스트 실행 가능
원본 Phase 3: UI가 없어도 도시가 독립적으로 진행됨
