# Phase 3 — 시민 이동
> 원본: README §12 Phase 6(시민 이동 시각화), §4.4, §8.4

## 목표
엔진이 결정한 시민의 논리적 이동을 프론트엔드가 도로망 기반 경로와 애니메이션으로 표현한다.

## 작업
- 시민 이동 시각화
- §4.4: 시민은 논리적 출발지, 목적지, 이동 시작 Tick 및 예상 도착 Tick을 가진다. 시뮬레이션 엔진은 이동의 시작과 완료를 결정한다. 프론트엔드는 도로망을 사용해 시각적 경로를 계산하고 이동 애니메이션을 표현한다.
- §8.4: 프론트엔드는 이동 이벤트를 받아 경로를 찾고 애니메이션을 재생한다. 렌더링 프레임 속도와 시뮬레이션 Tick은 서로 독립적으로 동작한다.

## 완료 기준
원본 Phase 6 완료 기준: 사용자가 도시를 관찰하고 소득세율을 변경한 후 경제적 변화를 확인할 수 있음

(재구성) 사용자가 브라우저를 닫더라도 시민의 논리적 이동은 정상적으로 진행되고, 프론트엔드는 이동 이벤트로 경로를 찾아 애니메이션을 재생함
