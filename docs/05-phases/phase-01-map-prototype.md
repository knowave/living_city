# Phase 1 — 맵 프로토타입
> 원본: README §12 Phase 1(프로젝트 기반), Phase 2(렌더링 기반)

## 목표
개발 환경과 테스트 기반을 갖추고, Three.js(React Three Fiber)로 지형·도로·건물을 OrthographicCamera 시점에서 렌더링하며 카메라 이동·줌과 타일 선택을 제공한다.

## 작업
- Repository 구성과 개발 환경 설정
- 테스트 기반 구성
- Three.js/R3F 씬 초기화
- 지형·도로·건물 렌더링 (OrthographicCamera)
- 카메라 이동 및 줌
- 타일 선택
- 기본 Geometry(박스)로 샘플 건물 20개 렌더링 (하드코딩 샘플 데이터, 도로·다른 건물과 겹치지 않음)
- 건물 클릭 선택: 왼쪽 위 패널에 건물 ID와 타입 표시, 선택 건물 강조, 빈 땅 클릭 시 선택 해제, 드래그는 클릭으로 처리하지 않음
- 평균 FPS 확인: 오른쪽 위 패널에 최근 1초 FPS와 페이지 로드 후 누적 평균 FPS 표시 (0.5초마다 갱신, 성능 목표 없음)

## 완료 기준
원본 Phase 1: 세계 상태와 핵심 도메인을 코드로 표현하고 단위 테스트 실행 가능
원본 Phase 2: 도시 맵을 자유롭게 탐색하고 건물을 선택할 수 있음

(재구성) 개발 환경에서 단위 테스트가 실행되고, 도시 맵을 카메라로 자유롭게 탐색하며 타일을 선택할 수 있음
샘플 건물 20개가 도로·다른 건물과 겹치지 않게 렌더링됨
건물을 클릭하면 왼쪽 위 패널에 ID와 타입이 표시되고 선택 건물이 강조되며, 빈 땅 클릭 시 선택이 해제되고, 드래그는 선택으로 처리되지 않음
오른쪽 위 패널에 최근 1초 FPS와 누적 평균 FPS가 0.5초마다 갱신되어 표시됨
