# Phase 5 — 경제 시스템
> 원본: README §12 Phase 1(경제 거래 모델), Phase 4

## 목표
경제 거래 모델을 확정하고 고용·급여·세금·소비·복지·기업 활동을 경제 원장에 기록해 검증 가능한 자금 흐름을 만든다.

## 작업
- 경제 거래 모델 확정
- 고용 및 구직
- 급여 지급
- 소득세 징수
- 소비와 매출
- 복지
- 기업 채용, 해고 및 파산
- 경제 원장

## 완료 기준
원본 Phase 4: 시민, 기업, 정부 사이에 검증 가능한 자금 흐름이 존재함
