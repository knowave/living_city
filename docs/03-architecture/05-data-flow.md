## 4.4 이동 행동

시민은 논리적 출발지, 목적지, 이동 시작 Tick 및 예상 도착 Tick을 가진다.

시뮬레이션 엔진은 이동의 시작과 완료를 결정한다.

프론트엔드는 도로망을 사용해 시각적 경로를 계산하고 이동 애니메이션을 표현한다.

사용자가 브라우저를 닫더라도 시민의 논리적 이동은 정상적으로 진행된다.

9. 변경 사항과 이벤트 원자적 저장

## 8.4 시민 이동 렌더링

Python 엔진은 이동 목적과 논리적 도착 시점을 결정한다.

프론트엔드는 이동 이벤트를 받아 경로를 찾고 애니메이션을 재생한다.

렌더링 프레임 속도와 시뮬레이션 Tick은 서로 독립적으로 동작한다.

## 9.3 이벤트 복구

모든 동기화 이벤트는 세계별 증가하는 Sequence를 가진다.

클라이언트는 초기 상태와 이벤트 커서를 조회하고, 해당 커서 이후 이벤트부터 SSE를 수신한다.

연결이 끊기면 마지막 이벤트 이후의 데이터를 재전송받는다.

이벤트 재전송이 불가능하면 최신 스냅샷을 다시 조회한다.

## 9.4 일관성 원칙

- 서버가 세계 상태의 최종 권한을 가진다.
- 클라이언트가 계산한 애니메이션 위치는 영속 상태를 변경하지 않는다.
- 서버의 실제 상태 변경은 저장 성공 후에만 이벤트로 전달한다.
- 중복 SSE 이벤트는 Sequence 기준으로 무시한다.
- 정책 변경 명령은 지정된 Tick 경계에서 적용한다.
